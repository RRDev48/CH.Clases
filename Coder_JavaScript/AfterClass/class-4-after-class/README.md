## Contexto

El presente simula un formulario de contacto donde un usuario podrá ingresar los datos solicitados en los "inputs" de este fomrulario (simulado con los prompts y las variables) y devolver un mensaje de éxito para indicar al usuario que su solicitud fue envíada. Al mismo tiempo se imprimirá en la consola un detalle de los datos ingresados, para simular la lista en formato de lista del operador del otro lado del sistema (backoffice). 

## Para simular el proceso

Para simular el proceso, al abrir la página comenzará decidiendo si quiere o no cargar un formulario de contacto, si ingresa SI en el input del prompt, se solicitarán los datos requeridos para el formulario (apellidos, nombres, coreo electrónico y mensaje). Al final se mostrará un mensaje de éxito y un mensaje en consola.
